# دبّوس 📍

لعبة خرائط وأعلام جماعية: شاشة كبيرة + كل لاعب من جواله.

## الرفع على GitHub Pages
1. ارفع كل الملفات اللي بهالمجلد (index.html و atlas-50m.json و atlas-110m.json و land-110m.json و .nojekyll) لنفس المكان بالريبو.
2. Settings ← Pages ← اختار الـ branch والمجلد ← Save.
3. افتح الرابط على اللابتوب واختار «الشاشة الكبيرة».
4. الجوالات بتمسح الـ QR أو بتفتح نفس الرابط وبتدخل كود الغرفة.

الاتصال بين الأجهزة بيصير عن طريق PeerJS (مجاني، بدون سيرفر). لازم يكون في نت.

## الأغاني 🎵
حط ملفات الأغاني بنفس المجلد جنب index.html بهالأسماء بالزبط:
- `lobby.mp3` — باللوبي
- `game.mp3` — وقت اللعب (بتوطى لحالها وقت كشف الجواب)
- `awards.mp3` — بالجوايز آخر اللعبة

اللعبة بتلاقيهم لحالها. وإذا رفعت أغنية من اللوبي بإيدك، بتغلب على الملف.
